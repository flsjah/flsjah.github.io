다시보기 업로더

YouTube 영상 자동 업로드 도구

소개

다시보기 업로더는 Windows PC에서 녹화 영상을 선택해 올리거나, 지정한 폴더의 새 녹화 영상을 사용자가 연결한 YouTube 채널에 자동 업로드하는 프로그램입니다. Google 로그인과 권한 허용 후 YouTube Data API를 사용합니다.

이 앱이 하는 일

  • 사용자가 연결한 채널과 영상 목록·메타데이터를 조회합니다.
  • 선택한 영상을 수동 또는 자동으로 업로드하고 공개 범위·예약 공개 등 지원되는 설정을 적용합니다.
  • 사용자가 선택한 썸네일을 업로드하고, 요청한 영상 제목을 수정하거나 재생목록에 영상을 추가합니다. 일부 기능에는 추가 권한이 필요합니다.
  • 영상 미리보기·썸네일 편집·이미지 배경 제거는 사용자 PC에서 처리합니다.
  • 수익 창출과 광고 적합성은 이 프로그램에서 설정할 수 없으며 YouTube Studio에서 직접 설정해야 합니다.

데이터와 로그인

로그인 정보·채널별 설정·업로드 기록은 사용자 PC에서 관리하며, 제작자 서버에 자동으로 전송하지 않습니다. 인증과 영상 관리에 필요한 정보는 Google로 전송됩니다. 자세한 저장·전송·삭제 방법은 개인정보처리방침에서 확인하세요.
