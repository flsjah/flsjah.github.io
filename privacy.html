개인정보처리방침

시행일: 2026년 11월 5일

다시보기 업로더(이하 “본 앱”)는 Windows PC에서 실행되는 YouTube 영상 관리 프로그램입니다. 본 안내는 본 앱이 접근·사용·저장·전송하는 정보를 설명합니다.

1. 접근하고 처리하는 정보

  • Google 로그인 과정에서 발급되는 OAuth 인증 토큰과 사용자가 연결한 YouTube 채널의 이름·핸들·식별자
  • 연결한 채널의 영상 목록, 제목·설명·태그·공개 상태·영상 길이·촬영 날짜 등 API에서 제공되는 메타데이터 및 재생목록 정보
  • 사용자가 지정한 폴더와 영상·이미지 파일, 제목·설명·태그·공개 범위·예약 시각 등 업로드 설정
  • 업로드 진행 상태·영상 식별자·중복 업로드 방지 정보와 오류기록

2. 정보의 사용 목적

사용자의 요청에 따라 채널·영상 정보를 조회하고, 영상과 썸네일을 업로드하며, 지원되는 업로드 설정을 적용하고, 영상 제목 수정과 재생목록 추가를 처리합니다. 지정한 폴더의 자동 업로드와 중단된 업로드의 이어 올리기에도 정보를 사용합니다. 일부 편집 기능에는 추가 Google 권한을 요청할 수 있습니다.

미리보기 생성·썸네일 편집·이미지 배경 제거는 사용자 PC에서 처리합니다. 수익 창출 설정과 광고 적합성 평가는 본 앱에서 처리하지 않습니다.

3. 정보의 저장과 보관

제작자 서버에는 로그인 토큰·영상·사용 기록을 자동으로 수집하거나 저장하지 않습니다. 본 앱의 기본 데이터 저장 위치는 사용자 PC의 %LOCALAPPDATA%\ReplayUploader입니다.

  • “로그인 유지”를 켜면 인증 토큰을 Windows 사용자별 암호화 기능으로 로컬 저장합니다. 끄면 저장된 토큰을 제거하고 이번 실행 중 메모리에서만 유지합니다.
  • 폴더 경로·제목·설명 등 설정과 업로드 기록은 로컬 저장됩니다. 설정은 채널별로 관리되며 같은 채널을 다시 연결할 때 복원됩니다.
  • 오류기록은 실행 파일 옆의 “오류기록” 폴더에 저장하며, 그 위치에 쓸 수 없으면 앱 데이터 폴더에 저장합니다. 파일 경로와 오류 내용 등이 포함될 수 있으며 인증정보를 가리도록 처리합니다.
  • 설정·업로드 기록은 로그아웃만으로 모두 삭제되지 않으며 사용자가 로컬 데이터를 삭제할 때까지 보관될 수 있습니다.

4. Google로의 전송

인증 토큰은 Google 인증 및 YouTube API 요청을 위해 Google로 전송됩니다. 사용자가 요청한 업로드·수정 작업에는 영상·썸네일과 필요한 제목·설명·설정 등도 Google로 전송됩니다. Google 인증 및 API 통신에는 HTTPS를 사용합니다.

제작자 서버나 별도의 이미지 배경 제거 서비스로 영상·이미지를 자동 전송하지 않습니다. 사용자가 직접 오류기록을 배포자에게 전달하는 경우에는 해당 파일에 포함된 정보가 전달됩니다.

5. 정보의 판매·공유와 Google API 정책

본 앱은 사용자 정보를 판매하지 않습니다. 위에 설명한 Google 서비스 이용과 사용자의 직접적인 전달 외에, 사용자 정보를 광고·마케팅 또는 제3자의 독립적인 목적으로 제공하지 않습니다.

본 앱의 Google API에서 받은 정보 사용과 다른 앱으로의 전달은 제한된 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

YouTube 서비스 이용에는 YouTube 서비스 약관이 적용됩니다. Google의 정보 처리 방식은 Google 개인정보처리방침에서 확인할 수 있습니다.

6. 로그아웃과 권한 철회

로그아웃하면 자동 감시와 대기열 전송을 멈추고 이 PC의 등록된 채널 인증을 삭제하며, 설정·영상 목록·기록 화면을 비웁니다. 채널별 설정과 업로드 기록은 로컬에 남습니다. Google 브라우저 계정에서는 별도로 로그아웃해야 합니다.

Google 측 앱 접근 권한은 Google 계정의 제3자 연결 관리에서 해제할 수 있습니다. 로컬 로그아웃은 Google 측 권한 철회를 대신하지 않습니다.

7. 로컬 데이터 삭제

모든 로컬 인증·설정·업로드 기록을 삭제하려면 먼저 프로그램을 종료한 뒤 %LOCALAPPDATA%\ReplayUploader 폴더를 삭제하세요. 별도 데이터 폴더를 지정한 경우에는 그 폴더를 삭제하세요. 실행 파일 옆에 생성된 오류기록은 해당 폴더에서 별도로 삭제할 수 있습니다.

프로그램의 “완료 기록 지우기”는 목록을 정리하는 기능입니다. 중복 방지 등을 위한 내부 정보까지 모두 삭제하는 기능은 아닙니다. 로컬 데이터 삭제나 기록 정리는 원본 영상이나 이미 YouTube에 업로드된 영상을 삭제하지 않습니다.

8. 변경과 문의

프로그램의 정보 처리 방식이 바뀌면 본 안내와 시행일을 갱신합니다.
