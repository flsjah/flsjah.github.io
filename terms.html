1. 프로그램과 기능

다시보기 업로더는 Windows PC에서 사용자가 연결한 YouTube 채널의 영상 정보를 조회하고, 영상·썸네일 업로드, 지원되는 업로드 설정, 영상 제목 수정 및 재생목록 추가 등을 돕는 프로그램입니다. 일부 기능에는 추가 Google 권한이 필요합니다.

수익 창출과 광고 적합성은 프로그램에서 설정하지 않으며 YouTube Studio에서 직접 설정·확인해야 합니다. 이 프로그램은 Google 또는 YouTube가 제공하는 공식 프로그램이 아닙니다.

2. 사용자의 계정과 콘텐츠

사용자는 자신이 접근 권한을 가진 채널을 연결하고, 업로드·편집 권한이 있는 영상과 이미지·음원·폰트 등만 사용해야 합니다. 다른 사람의 계정이나 권리를 침해하거나, 서비스 제한을 회피하는 용도로 프로그램을 사용해서는 안 됩니다.

업로드 대상 채널, 파일, 제목, 공개 범위와 예약 시각은 실행 전에 확인하세요. 자동 업로드는 사용자가 켜 둔 동안 지정한 폴더와 시작 당시의 설정을 사용합니다. 설정 변경 시 자동 모드를 껐다 다시 켜세요.

3. YouTube API 서비스

본 프로그램은 YouTube API 서비스를 사용합니다. 프로그램을 이용하는 사용자는 YouTube 서비스 약관의 적용을 받습니다. YouTube 및 Google이 정한 정책과 사용 제한을 준수해야 합니다.

Google 인증 상태, API 할당량, 서비스 정책, 네트워크 및 PC 환경에 따라 로그인이나 업로드가 제한되거나 중단될 수 있습니다. 업로드 시각·처리 완료 시각·공개 상태는 YouTube Studio에서 최종 확인하세요.

4. 로컬 파일과 자동 기능

원본 파일은 사용자가 별도로 백업·관리하세요. 다시 업로드는 기존 YouTube 영상을 교체하지 않고 새 영상으로 추가할 수 있습니다. 완료 기록 정리는 원본이나 YouTube 영상을 삭제하지 않습니다.

업로드 완료 후 PC 종료 기능은 사용자가 켠 경우에만 동작합니다. 다른 작업의 저장 여부를 먼저 확인하세요. 자동 업로드를 계속 사용하려면 프로그램과 PC가 실행 중이어야 합니다.

5. 개인정보와 접근 권한

접근하는 정보, 저장·전송 및 삭제 방법은 개인정보처리방침에 설명되어 있습니다. 사용자는 로그인 유지 여부를 선택하고, 로그아웃하거나 Google 계정에서 앱의 접근 권한을 해제할 수 있습니다.

6. 기능 및 약관의 변경

프로그램 업데이트나 외부 서비스 변경에 따라 제공 기능과 이용 방법이 바뀔 수 있습니다. 약관이 변경되면 이 페이지의 내용과 시행일을 갱신합니다. 이 안내는 관련 법령상 인정되는 사용자의 권리를 제한하지 않습니다.
